# Сайт школы барабанов DrumMaks

Волгоград, улица Землячки, 27Д. Одностраничный сайт: уроки, цены, отзывы, запись на пробный урок.

## Что здесь лежит

| Файл | Зачем |
|---|---|
| `index.html` | вся страница |
| `styles.css` | оформление |
| `script.js` | форма записи, кнопка «на раздел выше», окно с видео |
| `beat.js` | звук установки: барабаны синтезируются прямо в браузере, аудиофайлов нет |
| `privacy.html` | политика обработки персональных данных |
| `media/` | фотографии и видео |

## Как обновляется

Рабочая версия сайта живёт на компьютере в `school\site\www`. Эта папка — копия,
собранная скриптом `school\site\sobrat-dlya-publikacii.ps1`, и только она уезжает в интернет.
Серверная часть формы (`send.php`) в копию не попадает: на GitHub Pages PHP не работает.

## Форма записи

На GitHub Pages заявка не отправляется — там нет сервера. Форма оживёт на боевом хостинге
с PHP или на серверной функции. Телефон и ссылки на странице работают всегда.
